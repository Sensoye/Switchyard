## 🎯 What Is Switchyard?

Switchyard is a simple yet powerful tool that helps your computer programs talk to artificial intelligence services. If you use programs that work with AI models (like ChatGPT or Claude), Switchyard acts as a smart traffic controller. It decides which AI service should handle each request, based on what you need—whether that's speed, cost, or quality.

Think of it like this: you have several delivery companies (AI providers). Switchyard is the dispatcher that sends each package (your request) to the best company for the job. Sometimes you want the cheapest option, sometimes the fastest, and sometimes the one that gets the best results. Switchyard makes that choice automatically.

The best part? You don't need to change anything about your existing programs. Switchyard works with the same language that OpenAI and Anthropic already use, so it plugs right in without any complicated setup.

## 🔧 Troubleshooting Common Issues

### Problem: "No connection" error
- Check your internet connection
- Verify your API keys are correct
- Make sure at least one provider is active

### Problem: Slow responses
- Check if you're using a slow provider
- Adjust routing rules to prefer faster models
- Ensure your computer meets the recommended requirements

### Problem: Costs higher than expected
- Review your routing rules
- Switch to budget-friendly providers
- Set spending limits in the settings

### Problem: Can't connect to a specific provider
- Check that provider's service status
- Verify your API key hasn't expired
- Try removing and re-adding the provider
